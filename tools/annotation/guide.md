# PinTrace 标注工具使用说明

版本 v1.0（2026-11-08）

本说明介绍标注工具怎么用。**每个标签的含义和判定规则请看《编码手册》**。

> 说明中的截图来自练习题，截图里选中的答案只是操作演示，不代表正确答案。

---

## 1 你会收到的文件

| 文件 | 用途 |
|---|---|
| `PinTrace_practice.html` | 练习题（20 条），不计入结果 |
| `PinTrace_annotation_A1.html` 或 `…_A2.html` | 正式标注（约 400 条），每人一份，请只打开发给你的那份 |
| `PinTrace_编码手册_v1.0.pdf` | 标签定义与判定规则 |
| `PinTrace_标注工具使用说明_v1.0.pdf` | 本说明 |

---

## 2 打开工具

1. 把 `.html` 文件保存到电脑上一个固定的文件夹，比如"文档"，**之后不要移动或改名**。
2. 双击文件，用 **Microsoft Edge** 或 **Google Chrome** 打开。如果默认打开的是别的程序，右键 →"打开方式"→ 选 Edge 或 Chrome。
3. 不需要联网，也不需要安装任何东西。只有点 GitHub 链接时才需要联网。

**请注意**

- 不要用浏览器的无痕或隐私模式，否则关闭后答案会丢失。
- 标注期间不要清除浏览器数据（缓存、Cookie、网站数据）。
- 始终用**同一台电脑、同一个浏览器**打开。如果需要换电脑，见第 7 节"导入答案"。
- 如果页面顶部出现红色提示"当前浏览器不能保存进度"，请换用 Edge 或 Chrome；实在不行，就每次结束前都导出一次答案。

## 3 界面总览

![界面总览](images/overview.png)

| 编号 | 区域 | 说明 |
|---|---|---|
| ① | 进度 | 已答题数和总题数 |
| ② | 题号导航 | 点数字跳到对应题目，颜色含义见第 5 节 |
| ③ | 题目 | 当前题目要回答的问题 |
| ④ | 链接 | "查看这次提交"和"前后对比"会在 GitHub 上打开完整改动；材料不够判断时再点 |
| ⑤ | 关注的引用 | 左边是变更前，右边是变更后。每张卡片显示 `uses:` 的值、文件位置、行尾注释，以及该行上下文（黄色为该行） |
| ⑥ | 文件改动 | 这次提交对相关文件的改动：红色 `-` 为删除的行，绿色 `+` 为新增的行，两列数字分别是改动前后的行号 |
| ⑦ | 导出答案 | 完成后点这里导出，见第 6 节 |

**几点说明**

- 一侧显示"没有列出引用"，表示这道题在那一侧没有关注的引用，例如新增或删除的情况。
- 新增或删除整个文件时，文件改动默认折叠，需要时点"文件改动"那一行展开。
- 文件改动太长时只显示与关注引用有关的部分，末尾会提示还有多少行未显示，可点 GitHub 链接查看完整内容。

## 4 作答

![作答区](images/answer.png)

| 编号 | 操作 |
|---|---|
| ① | **点选一个标签**。按钮下方的小字是简要提示，完整定义见《编码手册》 |
| ② | **选择把握程度**：高、中、低 |
| ③ | **备注**（选填）。选 `unknown`、`mixed` 或把握程度为低时，请写一句原因 |
| ④ | 上一条、下一条 |

- 答案**点选后立即自动保存**，没有"提交"按钮。
- 想改答案，直接点另一个标签即可。
- **快捷键**（光标不在备注框里时有效）：
    - 数字键 `1`–`9`、`0`：选择对应编号的标签（按钮上标有编号）；
    - 方向键 `←` `→`：上一条、下一条。

---

## 5 查看进度、跳转

![题号导航](images/nav.png)

| 颜色 | 含义 |
|---|---|
| 绿色 | 已作答 |
| 黄色 | 已作答，但选了 `unknown` 或把握程度为低，方便你回头复查 |
| 白色 | 未作答 |
| 蓝色边框 | 当前题目 |

- 勾选"只看未答"后，导航里只显示还没答的题。
- 顶部的"下一条未答"按钮会直接跳到下一道未答题。
- 可以分多次完成。关掉页面后再次打开，会回到上次的位置，已答内容都在。

---

## 6 导出并提交答案

![顶部按钮](images/header.png)

1. 全部答完后，点右上角蓝色的 **导出答案**。
2. 如果还有未答题目，会弹出提示；可以先回去补完，也可以照常导出当前进度。
3. 浏览器会下载一个文件，名字类似 `PinTrace_A1_answers_20261120-1530.csv`，一般在"下载"文件夹里。
4. 把这个 CSV 文件**单独**发给组织者，例如通过邮件或微信文件。

**请注意**

- 不要用 Excel 打开后再保存这个文件，也不要改动其中内容，直接原样发送。
- 建议每次标注结束时都导出一次，作为备份。备份文件不需要发送，最后一次完整导出的那份才需要。

---

## 7 导入答案（换电脑或恢复进度）

如果需要换电脑，或者浏览器数据被意外清除：

1. 在新电脑上打开**同一份** `.html` 文件；
2. 点顶部的 **导入答案**，选择你之前导出的 CSV 文件；
3. 确认后，答案就恢复了，可以接着标注。

工具只接受同一份标注包导出的文件。导入别人的文件会被拒绝。

---

## 8 练习题流程

1. 先读完《编码手册》。
2. 打开 `PinTrace_practice.html`，完成 20 道练习题（顶部有蓝色提示"这是练习题"）。
3. 导出答案发给组织者。组织者会回一份书面讲解，说明每题的判定依据。
4. 看完讲解后再开始正式标注。如果规则有补充，组织者会同时发给两位标注者一份新版手册或 FAQ。

## 9 常见问题

**问：打开后一片空白，或者显示乱码。**
答：请确认用的是 Edge 或 Chrome。文件约 2 MB，打开可能需要几秒。

**问：GitHub 链接打不开或很慢。**
答：大多数题目不需要点链接，页面里的材料已经足够判断。实在无法确认时，选 `unknown` 并在备注写"无法打开链接确认"。

**问：遇到规则上的疑问怎么办？**
答：把问题发给组织者，不要和另一位标注者讨论具体题目。组织者会把答复整理成 FAQ，同时发给两人。

**问：中途想修改之前的答案可以吗？**
答：可以。在导航里点对应题号回去修改，最后导出时以最新答案为准。

**问：一次要标多久？**
答：正式标注约 400 条，每条 1–1.5 分钟，建议分几次完成，每次 1–2 小时，注意休息。
